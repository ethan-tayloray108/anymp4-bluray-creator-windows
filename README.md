## What AnyMP4 Blu-ray Creator Does

AnyMP4 Blu-ray Creator is a Windows desktop application for turning videos, photos, and audio into Blu-ray discs. It provides a single workspace for arranging media, configuring the disc structure, preparing menus, and creating the final Blu-ray rather than requiring separate tools for each stage.

The authoring workflow supports a selection of video and audio formats, subtitle and audio track configuration, and menu creation through included templates. You can also preview the project before burning to check its organization and adjust the setup as needed.

## Using the Application

The basic authoring process is:

1. Open AnyMP4 Blu-ray Creator.
2. Import the video clips, photos, and audio files for the project.
3. Select a disc menu template and customize it as required.
4. Configure subtitle and audio track settings where applicable.
5. Preview the project and verify its layout and playback sequence.
6. Start the burning operation to create the Blu-ray disc.

For a batch project, import all required files before authoring, then check their order and the project options before beginning the creation process.
